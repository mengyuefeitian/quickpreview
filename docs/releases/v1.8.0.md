RAR 压缩包现在也能按空格预览了，包里有几个文件、多大、什么时候改的，一眼看清。

### 新增

- **RAR 压缩包预览**：支持 RAR5 与老版 RAR4。清单列出完整路径、原始大小、压缩后大小与修改时间，可按文件名筛选；以「存储」方式打包的条目点开直接看内容，真正压缩过的条目会说明原因（RAR 是专有算法，浏览器里没有解压器）。
- **大包不整包读**：超过 64MB 的包只按需读块头，45MB 的包实测只读 3.7MB，点开条目时才取那一个文件的数据 —— 与 1.7.0 修的闪退是同一类防护。

### 安装

下载 `QuickPreview-Setup-1.8.0-x64.exe` 覆盖安装即可，设置与窗口位置保留。Windows 10 1903+ / 11 x64，  
自包含 .NET 8 运行时，无需管理员权限；安装包未签名，首次运行如遇 SmartScreen 请点「更多信息 → 仍要运行」。

逐条变更见 [CHANGELOG](https://github.com/mengyuefeitian/quickpreview/blob/main/CHANGELOG.md)。
