加密 PDF 现在能直接在预览里输密码打开，超大压缩包也不会再把程序带走。

### 新增

- **加密 PDF 密码输入**：预览区弹出密码框，按回车或点「打开」即可；密码错误会提示并允许重试，输对直接进入翻页浏览。取消则回到原处，不会卡住。

### 修复

- **预览 1.5GB 压缩包导致程序闪退**：以前会把整个包一次读进内存，1.5GB 的响应体直接压垮浏览器进程。现在大包只按需读取索引（实测 55ms 出清单），点开包内文件时才读取那一个文件的数据。

### 安装

下载 `QuickPreview-Setup-1.7.0-x64.exe` 覆盖安装即可，设置与窗口位置保留。Windows 10 1903+ / 11 x64，
自包含 .NET 8 运行时，无需管理员权限；安装包未签名，首次运行如遇 SmartScreen 请点「更多信息 → 仍要运行」。

逐条变更见 [CHANGELOG](https://github.com/mengyuefeitian/quickpreview/blob/main/CHANGELOG.md)。
