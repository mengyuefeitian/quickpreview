常驻托盘的 Windows 预览服务：资源管理器里选中文件按空格就能看内容，不改你的文件管理习惯。

### 新增

- **全局空格预览**：只在资源管理器前台且有选中项时接管空格，其余一律放行，不影响别处打字。
- **纯原生实现**：托盘常驻、无主界面、无需管理员权限；内置 ffmpeg，非浏览器原生封装的音视频自动转码并缓存。
- **支持格式**：图片、文本与代码、PDF、Word、Excel、PPT、压缩包、音频、视频。
- **快捷操作**：开机自启、Esc 关闭、←/→ 切换同目录文件、滚轮翻页。

### 安装

下载 `QuickPreview-Setup-1.0.0-x64.exe` 覆盖安装即可，设置与窗口位置保留。Windows 10 1903+ / 11 x64，
自包含 .NET 8 运行时，无需管理员权限；安装包未签名，首次运行如遇 SmartScreen 请点「更多信息 → 仍要运行」。

逐条变更见 [CHANGELOG](https://github.com/mengyuefeitian/quickpreview/blob/main/CHANGELOG.md)。
