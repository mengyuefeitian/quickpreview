## v1.6.0 — 四类真实反馈集中修：代码文件、翻页乱跳、音视频、误报管理员

_发布日期：2026-10-21_

本版处理的是用户反馈里最集中的四类问题：代码文件不能预览、滚轮翻页会乱跳文件、
音视频不自动播放且缺参数标注、以及那条一直误报的「需要以非管理员启动」。

### 新增
- **代码与配置文件预览**：`.py` `.ps1` `.bat` `.cmd` `.sh` `.java` `.go` `.rs` `.c/.cpp/.cs`
  `.sql` `.toml` `.yaml` …… 共 **141 个扩展名** + `Makefile` / `Dockerfile` / `LICENSE`
  等 **16 个无扩展名文件** 都能按空格预览，按语言高亮并按 UTF-8 解码（此前会当二进制流显示乱码）。
- **音视频自动播放**：打开即播，不再需要手动点一下播放按钮。音频若被浏览器策略拦下会记日志，
  视频则自动降级为静音播放，至少保证画面能动。
- **底部参数标注**：图片显示「1920 × 1080 px · 2.4 MB」；音视频显示「1280 × 720 · 1:23 · video/mp4 · 84 MB」，
  时长、分辨率、编码与体积一目了然。

### 修复
- **滚轮翻到最后一页会跳到随机文件**：翻页到首页/末页之后不再切换文件，滚轮只在当前文档内翻页；
  切换文件只认方向键，且一次只走一格，不会再连环跳。
- **大视频点关闭就崩溃**：本地文件服务此前用 `File.ReadAllBytes` 整文件读进内存，
  播放器并发发来多个 Range 请求时内存翻几倍直接 OOM。改为按区间流式读取
  （实测 202MB 文件只取 1MB 区间：0–1,048,575 / 共 211,680,078）。
- **桌面文件夹里预览的不是当前选中项**：桌面 ShellWindow 与同 hwnd 的多标签窗口会把"上次选中的文件"
  混进结果。现在加了窗口 class 与父目录双重校验，只认当前窗口目录下的选中项。
- **「需要以非管理员启动」误报**：关掉 UAC 时双击运行本身就带管理员令牌，而资源管理器同级别，
  读取完全正常 —— 提示却照弹。现在只在「确实读不到选中项」时才提示，且整轮只提示一次。
- **MKV / 大视频预览慢**：先探测编码，h264 / hevc / av1 / vp9 + aac / mp3 一律走 **remux（不重编码）**，
  实测 mkv 从 2646ms 降到 **534ms**，画质零损失；只有编码不被浏览器接受时才重编码。
- **FLAC 加载慢**：FLAC / MOV 此前被误判为需要转码，白白跑一遍 ffmpeg；现在直接原生播放。

### 工程
- 新增 `test-samples/check_ext_parity.py`：校验前端（`src/shared/mime.ts`）与宿主（`FileTypes.cs`）
  两份扩展名表是否一致 —— 这两份表一旦漂移，就会出现"右键看着支持、按空格却没反应"。
- 渲染进程崩溃/无响应此前完全没有监听，出问题只表现为白屏。现在会记日志，
  且 GPU / 解码这类子进程崩溃（Chromium 会自动重启）不再刷成 ERROR，避免淹没真正的问题。

### 验证
- 扩展名一致性：141 个扩展名 + 16 个特殊文件名，两侧完全一致。
- 代码文件预览 5/5 通过（`.py` / `.ps1` / `.bat` / `Dockerfile` / `Makefile`）。
- 全类型渲染回归（图片 / 文本 / Word / Excel / PowerPoint）：4/4、3/5 ——
  本机无显卡环境 PDF 与部分渲染会触发 GPU 子进程崩溃，已用未改动的上一版安装包对照确认属环境问题。
- 大文件区间取流：202MB 音频只取 1MB，不再整文件读入。
