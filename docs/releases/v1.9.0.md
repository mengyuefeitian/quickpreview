托盘菜单多了一项「检查更新」，默认每 6 小时还会自己查一次；发现新版本后点「立即更新」，剩下的下载、校验、安装、重启全自动。

### 新增

- **检查与提示** — 手动查或定时查，发现新版本会列出更新内容，可以「稍后提醒」或「跳过此版」，不再被同一个版本反复打扰。
- **下载可核验** — 进度与实时速度可见；按 GitHub 提供的 sha256 摘要校验，不匹配直接丢弃，绝不拿半截文件去安装。
- **装完自己回来** — 静默安装后自动重新拉起，并提示已更新到哪个版本，设置与窗口位置保持不变。

### 安装

下载 `QuickPreview-Setup-1.9.0-x64.exe` 覆盖安装即可，设置与窗口位置保留。Windows 10 1903+ / 11 x64，  
自包含 .NET 8 运行时，无需管理员权限；安装包未签名，首次运行如遇 SmartScreen 请点「更多信息 → 仍要运行」。

逐条变更见 [CHANGELOG](https://github.com/mengyuefeitian/quickpreview/blob/main/CHANGELOG.md)。
