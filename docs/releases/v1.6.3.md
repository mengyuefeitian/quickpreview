## v1.6.3 — 加密压缩包不再直接「不支持」，至少把清单列出来

> 本文件汇总 1.6.2 与 1.6.3 的改动（1.6.2 未对外发布）。

### 修复

- **加密压缩包完全打不开，显示"不支持"**

  打开加密的 ZIP（例如内含 AES 加密条目的包）时，页面只会停在「解析压缩包…」，
  看上去就是"这格式不支持"。

  根因有两层，缺一层都修不好：

  1. JSZip 遇到加密条目（压缩方法 99）会**整个包一起抛错**
     `Encrypted zip are not supported`，**连文件清单都列不出来**。
     但 ZIP 的中央目录是明文结构 —— 文件名、大小、时间戳都在里面，
     加密的只是数据区，**列清单根本不需要解密**。
  2. 这个异常**根本没人接**：`renderPreview` 是 `async`，调用处却既没有 `await`
     也没有 `.catch`，同步 `try/catch` 抓不到异步 reject，
     于是变成 unhandled rejection —— 页面永远停在加载中，也不报错。

  现在：
  - 新增中央目录直读器（`src/renderer/lib/zipdir.ts`），JSZip 读不了的包
    自动退化成"清单模式"：照样列出全部文件名、大小、压缩后大小、修改时间，
    并在顶部明确说明原因 —— 「🔒 该压缩包已加密，需要密码才能解压 —— 以下仅列出文件清单」。
    文件行前缀显示 🔒，点击时给出具体原因（「该文件使用 AES 加密，需要密码才能解压」），
    不再显示"解压中…"吊着。
  - `renderPreview` 的调用处补上 `.catch`，任何渲染失败都会显示
    「预览失败：具体原因」，不再卡在加载状态。**这条影响所有格式，不只是压缩包。**

  顺带覆盖的边界（均用 Python `zipfile` 逐项对照验证过）：
  ZIP64（7 万条目）、中文文件名（UTF-8 与 GBK 两种编码）、目录条目、存储模式、带注释的包。

- **资源管理器多标签页下预览错位**（Windows 11 22H2+）
  在新标签页里选中文件按空格，打开的一直是第一个标签页选中的文件 ——
  选图片、压缩包、文件夹出来的都是同一个文件。

  根因：多标签页共享同一个顶层 hwnd，`ShellWindow.HWND` 全都等于它，
  按 hwnd 匹配会把每个标签页都判为命中，取第一个自然永远是标签页 1。

  最初版本的判据有三处缺陷，导致全部落空、退化回老行为：
  1. `IShellBrowser` 是直接用 `QueryInterface` 取的，实际返回 `E_NOINTERFACE`
     —— 正确路径是先拿 `IServiceProvider` 再 `QueryService`。
  2. 标题匹配用了完全相等，而多标签时窗口标题是
     「下载 和 2 个其他选项卡 - 文件资源管理器」，永远对不上。
  3. 找标签子窗口用的 `FindWindowEx` **只查直接子窗口**，标签窗口嵌深一层就返回 0。

  本版分别修正：标签子窗口改用 `EnumChildWindows` 递归枚举；
  `IShellBrowser` 改经 `IServiceProvider::QueryService` 获取；
  标题匹配改为前缀匹配并在命中多个时取名字最长的候选。
  三个候选层级（活动标签 → 标题 → 整窗口）逐级兜底，
  即使某个判据随着 Windows 更新失效，也不会退化成"永远取第一个标签页"。

  本机实测（`test-samples/dev_tab_test.py` 真实开多标签页 + 模拟按键）：
  标签1 有选中项、人在标签2 时，读取结果是"未读取到任何选中项"
  （修复前会直接读到标签1 的文件），且日志能明确区分
  「属于活动标签页」与「非活动标签页」。

- **空格补发死循环**：吞掉空格却没能打开预览时会补发一次空格，
  这个补发的空格又被自己的键盘钩子捕获，形成"补发 → 捕获 → 再补发"，
  一次按键刷出上千条日志并把 WebView2 拖崩。
  现在补发的按键在 `dwExtraInfo` 里带自补发标记，钩子见到直接放行，不再二次处理。

### 新增

  https://github.com/mengyuefeitian/quickpreview

### 说明
- 加密包只能列出清单，**内容仍需密码才能解压** —— 这是 ZIP 格式本身的限制，
  不是本程序的缺陷。请用压缩软件输入密码解压后再打开。
- 压缩包内嵌套的压缩包（"多层穿透"）**刻意不支持**，只解析第一层。

**安装包**：`QuickPreview-Setup-1.6.3-x64.exe` — Windows 10 1903+ / 11 x64，自包含 .NET 8 运行时与渲染引擎，安装无需管理员权限。安装包未做代码签名，首次运行如遇 SmartScreen 提示请点「更多信息 → 仍要运行」。
