新增按功能分开的日志与内置查看器，出问题不用再靠猜。

### 新增

- **六路日志**：app / hook / preview / media / web / error 各自独立文件，单文件 10MB 轮转、保留 2 份备份、最新在最上面。
- **内置日志查看器**：从托盘打开，可切文件与备份、自动刷新、清空，并能一键导出诊断包。
- **全链路埋点**：钩子存活、每次空格、前台窗口类名、选中项读取、预览开关、文件请求、ffmpeg 命令行与退出码、页面报错。
- 版本号改为单一来源，日志与界面不再各写一份。

### 修复

- 主窗体常驻隐藏导致 WebView2 拿不到窗口句柄；WebView2 未就绪时按空格毫无反馈；关闭预览后焦点没有还给资源管理器。

### 安装

下载 `QuickPreview-Setup-1.1.0-x64.exe` 覆盖安装即可，设置与窗口位置保留。Windows 10 1903+ / 11 x64，
自包含 .NET 8 运行时，无需管理员权限；安装包未签名，首次运行如遇 SmartScreen 请点「更多信息 → 仍要运行」。

逐条变更见 [CHANGELOG](https://github.com/mengyuefeitian/quickpreview/blob/main/CHANGELOG.md)。
