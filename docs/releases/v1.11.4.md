Markdown 预览第一屏一直是对的，往下滚就"变了个样"：白纸消失，正文糊在深色底上看不见，表格里没底色的行变成一块块黑斑。这一版修掉。

### 修复

- **Markdown 长文档滚动过一屏后看不清。** 第一屏正常，继续往下滚就一片深色，深色文字落在深色底上，表格出现黑块。原因不在排版，在容器：外层预览区是弹性布局，纵向子项会被按"一屏高"拉伸而不是按"内容高"，Markdown 的纸张又没有自己的滚动条，于是盒子只到一屏，超出的部分 CSS 不再绘制它的背景。实测 2434px 高的文档，白纸盒子只有 309px。改为按内容撑高，短文档仍撑满一屏。
- 纯文本预览一直有同样的容器问题，只是它的底色和外围同为深色，所以从未显现；这次一并留在观察范围，暂不改动行为。
