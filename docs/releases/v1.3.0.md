补齐老格式支持，重做 PDF 与 PPT 的渲染。

### 新增

- **`.doc`（Word 97-2003）支持**：自研二进制解析，正文与表格都能取；编码按实际字节判断，WPS 生成的文档也不乱码。
- **PDF 单页横向翻页**：方向键 / PageUp / PageDown 翻页，首末页再翻才切文件。
- **托盘「关于」**：版本、运行时、安装目录、支持格式、快捷键一览。

### 修复

- **PDF 画面被压扁**：所有页纵向堆叠、只约束宽度导致比例失真，改为一次渲染一页、按容器等比缩放。
- **PPT 背景整片发黑**：主题色只认一种写法，其余全部算成黑色。
- **桌面按空格仍然无效**：回收站等虚拟项排在第一位时会被整体放弃，现在先过滤再取。
- **空 Excel 工作表**导致整个文件预览失败。
- PPT 渲染补齐主题配色、渐变、图片填充、描边、阴影、表格合并、组合形状等。

### 安装

下载 `QuickPreview-Setup-1.3.0-x64.exe` 覆盖安装即可，设置与窗口位置保留。Windows 10 1903+ / 11 x64，
自包含 .NET 8 运行时，无需管理员权限；安装包未签名，首次运行如遇 SmartScreen 请点「更多信息 → 仍要运行」。

逐条变更见 [CHANGELOG](https://github.com/mengyuefeitian/quickpreview/blob/main/CHANGELOG.md)。
