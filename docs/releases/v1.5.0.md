一轮集中反馈的八项改进。

### 新增

- 超大文本分块加载，首屏 256KB、滚到底继续读，几个 GB 的日志也能打开。
- 标题栏按钮显示真实的默认程序名（Word / 记事本 / 照片…）。
- 窗口可拖动、可拖边框缩放，位置与大小自动记住。
- Word / PDF 支持单页·双页切换、适应窗口、底部缩放，标签始终显示真实百分比。
- ZIP 预览：条目列表 + 搜索 + 行内直接看图片和文本，不落盘解压。

### 修复

- PPT 内容与实际不符，母版占位提示文字被画了出来。
- **安装后预览一片空白**：安装器的目录清理把刚装好的资源一起删了。
- Word 预览整页空白（页面结构匹配错了类名）。
- 「适应窗口」只按宽度算，A4 页面明显溢出；改按宽高比取小值。

### 安装

下载 `QuickPreview-Setup-1.5.0-x64.exe` 覆盖安装即可，设置与窗口位置保留。Windows 10 1903+ / 11 x64，
自包含 .NET 8 运行时，无需管理员权限；安装包未签名，首次运行如遇 SmartScreen 请点「更多信息 → 仍要运行」。

逐条变更见 [CHANGELOG](https://github.com/mengyuefeitian/quickpreview/blob/main/CHANGELOG.md)。
