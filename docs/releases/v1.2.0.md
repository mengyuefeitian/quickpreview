文件之外，文件夹和桌面图标也能按空格看内容了。

### 新增

- **文件夹预览**：显示文件数与总体积，后台线程统计、3 秒超时截断并标注「部分」，大目录不会卡住。
- **桌面预览**：选中桌面图标直接按空格。

### 说明

桌面与普通文件夹的窗口结构不同，点击图标后焦点还会落在内层控件上，需要按层级回溯才能识别。回收站等虚拟项不支持，会明确提示而不是静默失败。

### 安装

下载 `QuickPreview-Setup-1.2.0-x64.exe` 覆盖安装即可，设置与窗口位置保留。Windows 10 1903+ / 11 x64，
自包含 .NET 8 运行时，无需管理员权限；安装包未签名，首次运行如遇 SmartScreen 请点「更多信息 → 仍要运行」。

逐条变更见 [CHANGELOG](https://github.com/mengyuefeitian/quickpreview/blob/main/CHANGELOG.md)。
