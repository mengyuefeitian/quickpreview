## QuickPreview 1.5.3

类 macOS Quick Look 的 Windows 系统级预览服务：常驻托盘，在「文件资源管理器」里选中文件按 **空格** 即弹出预览浮层。

### 安装
1. 下载下方 `QuickPreview-Setup-1.5.3-x64.exe`
2. 双击安装（可选开机自启），安装后程序常驻托盘、不显示自己的窗口
3. 在资源管理器里选中任意文件，按 **空格** 预览；再按空格或 `Esc` 关闭

> 未做代码签名，首次运行可能触发 SmartScreen 提示，选择「仍要运行」即可。
> 需要 WebView2 运行时（Win10 1903+ / Win11 通常已自带，安装包会检测并提示安装）。

### 本版修复
- **Word 封面文字层叠乱码**：文本框（`wps:txbx`）此前按 VML 绝对坐标渲染且不占文档流，导致「创建时间 / 公司网址 / 联系地址」整块压到大标题上；现按 VML 语义重算位置，绕排（wrapSquare）的框会让锚点段落预留高度。
- **Word 第 2 页起页眉页脚整片丢失**：Word 的语义是「节内没写引用就继承上一节」，预览引擎此前不实现继承，导致 26 页的手册只有第 1 页有页眉页脚；现在渲染前会把各节的 header/footer 引用补全。
- **封面被硬塞正文页眉页脚**：`w:titlePg`（首页不同）此前取不到「首页」定义时会退回默认页眉，现改为真正的空白页眉页脚。
- **带书签的目录条目异常**：目录整行被塞进标题栏导致标题折成两行、目录页比 A4 高出 300+ 像素，现已修正为单行 + 点线 + 右对齐页码。

### 校验
- 24 页的《安装部署手册》：全部 794×1123px，封面无页眉页脚、2~24 页页眉页脚齐全，目录 33 项单行带点线
- 另抽 3 份同类长文档（19 / 29 / 24 页）：页眉全覆盖，页脚只缺封面
- 全类型回归 10/10（png / txt / docx / xlsx / pptx / pdf / mp3 / flac / mp4 / mkv）
